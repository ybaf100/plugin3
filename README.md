# Group Survival System

Paper 26.3용 익명 그룹 서바이벌 플러그인.
서버에 누가 있는지 알 수 없고, 오버월드 좌표가 숨겨지며, 통신이 제한된 환경에서 생존하는 규칙을 제공합니다.

## 설치

**필요한 것**
- Paper **26.3**, Java **25**
- `plugins/` 폴더에 넣을 것

| 플러그인 | 필수 | 용도 |
|---|---|---|
| `GroupSurvivalSystem-x.y.z.jar` | ✅ | 이 플러그인 (GitHub Actions 빌드 결과물) |
| [PacketEvents](https://modrinth.com/plugin/packetevents) 2.14.0 이상 | ✅ | 이름 익명화, F3 좌표 숨김, 나침반 0,0 고정 등 패킷 처리 |
| [Apollo-Bukkit](https://modrinth.com/plugin/lunar-client-apollo) 1.3.0 이상 | 권장 | Lunar Client 감지와 Lunar 모드 제한 (없으면 이 두 기능만 꺼짐) |

**권장 `server.properties`**

| 항목 | 값 | 이유 |
|---|---|---|
| `hide-online-players` | `true` | 서버 목록에서 접속자 숨김 |
| `enable-query` | `false` | 외부 조회로 접속자 노출 방지 |
| `view-distance` | `18` | 렌더 거리 (서버가 버거우면 줄이기) |
| `simulation-distance` | `18` | 시뮬레이션 거리 (렉이 생기면 이것부터 줄이기) |
| `spawn-protection` | `0` | 0,0 근처에서 일반 플레이어도 건축 가능하게 |

**리눅스 서버는 UTF-8 로케일로 실행**하세요. 로그 폴더 이름이 한글이라, 아니면 로그가 기록되지 않습니다.
```bash
LANG=C.UTF-8 java -jar paper.jar --nogui
```

## 명령어

### 플레이어

| 명령어 | 별칭 | 설명 |
|---|---|---|
| `/강화` | `/upgrade` | 강화 창 열기 (체력 탭) |
| `/체력강화` | `/hp` | 강화 창의 체력 탭 열기 |
| `/성급함강화` | `/haste` | 강화 창의 성급함 탭 열기 |
| `/인증 <키>` | `/auth` | 첫 접속 인증 (채팅에 키를 쳐도 됨) |
| `/nv` | | 영구 야간투시 켜기/끄기 (강화 창 스위치와 같음) |

일반 플레이어는 **위 명령어만** 쓸 수 있습니다 (`communication.allowed-commands`). 그 외 명령어는 막히고 명령어 목록에서도 보이지 않습니다. OP(`gss.bypass.commands`)는 제한이 없습니다.

### 관리자 (콘솔 전용)

| 명령어 | 설명 |
|---|---|
| `gss elytra on` | 겉날개 허용 (액자에서 뗄 수 있고 활공 가능) |
| `gss elytra off` | 겉날개 금지 |
| `gss elytra status` | 현재 겉날개 상태 확인 |
| `gss health <플레이어>` | 체력 단계 확인 |
| `gss health <플레이어> <8~23>` | 체력 하트 수 변경 |
| `gss haste <플레이어>` | 성급함 단계 확인 |
| `gss haste <플레이어> <0~2>` | 성급함 단계 변경 (0 = 해금 안 함) |

- 게임 안에서는 OP라도 실행할 수 없고 콘솔(RCON 포함)에서만 됩니다.
- 강화 단계를 바꾸면 그 단계에 넣어 둔 재료는 초기화됩니다. 접속 중인 플레이어만 바꿀 수 있습니다.

## 기능

### 강화 창 (`/강화`)

상자 6줄 크기의 창 하나에서 체력·성급함 강화와 효과 스위치를 다룹니다.

| 위치 | 내용 |
|---|---|
| 왼쪽 세로줄 | 탭: 체력(빨간 염료) / 성급함(곡괭이) |
| 맨 윗줄 | 단계 로드맵: 초록 = 완료, 노랑(빛남) = 진행 중, 회색 = 잠김. 마우스를 올리면 그 단계의 재료가 보임 |
| 가운데 | 이번 단계 재료. 재료마다 세로 한 줄: 아이콘(숫자 = 남은 개수) + 아래 유리판 3칸 게이지(회색 → 노랑 → 초록) |
| 아랫줄 | 사용법(책) · 도전과제 조건(지식의 책, 조건이 있는 단계만) · 강화 버튼 · 야간투시 스위치 · 성급함 스위치 · 닫기 |

**재료 넣는 법**
- 창이 열린 상태에서 **내 인벤토리의 재료를 직접 클릭**해야만 들어갑니다. 자동 투입은 없습니다.
  - 좌클릭: 그 칸 전부 (필요한 만큼만 빠지고 나머지는 남음)
  - 우클릭: 1개
- 재료는 여러 번에 나눠서 넣을 수 있고, 서버를 재시작하거나 죽어도 넣은 양이 유지됩니다.
- 넣은 재료는 돌려받을 수 없습니다.
- 이름을 바꾼 아이템, 마법이 부여된 아이템도 종류만 맞으면 인정됩니다. 셜커 상자 안의 아이템은 해당되지 않습니다.
- 모든 재료가 차면 강화 버튼이 초록색으로 빛나고, 누르면 강화됩니다.
- **해금·강화는 반드시 버튼을 눌러야 됩니다.** 조건을 다 채워도 자동으로 올라가지 않습니다.
- 재료와 도전과제 조건을 모두 채운 순간 액션바에 "체력 강화 준비 완료! /체력강화 창에서 버튼을 눌러 강화하세요"처럼 알림이 뜹니다.
  - 마지막 재료를 넣었을 때, 마지막 도전과제를 달성했을 때(창이 닫혀 있어도) 알립니다.
  - 같은 단계에서는 한 번만 알리고, 다시 접속하면 준비된 강화를 한 번 더 알려줍니다.
- 도전과제 조건이 있는 단계는 재료를 다 넣어도 도전과제 수가 찰 때까지 버튼이 보라색("도전과제가 부족합니다")으로 남습니다. 아래 [도전과제 조건](#도전과제-조건) 참고.
- 창 안의 아이템은 꺼내거나 옮길 수 없습니다.

#### 체력 강화
- **8하트**에서 시작해 **23하트**까지 올릴 수 있습니다 (마크 기본은 10하트).
- 죽어도 강화는 유지됩니다. 강화하면 늘어난 만큼(1하트)만 체력이 찹니다.

| 단계 | 재료 |
|---|---|
| 8 → 9 | 사과 16 |
| 9 → 10 | 돌 64 |
| 10 → 11 | 철 주괴 32, 밀 64 |
| 11 → 12 | 자수정 조각 64, 콘크리트 64 (아무 색, 섞어도 됨) |
| 12 → 13 | 다이아몬드 16, 에메랄드 64 |
| 13 → 14 | 석영 블록 64, 블레이즈 가루 16 |
| 14 → 15 | 황금 사과 16, 위더 스켈레톤 해골 1, 복어 16 |
| 15 → 16 | 엔더의 눈 32, 엔드 수정 16 |
| 16 → 17 | 다이아몬드 64, 바다의 심장 1 |
| 17 → 18 | 다이아몬드 64, 엔더 드래곤 머리 2 |
| 18 → 19 | 다이아몬드 블록 32, 불사의 토템 4 |
| 19 → 20 | 다이아몬드 블록 64, 신호기 1 |
| 20 → 21 | 네더 사마귀 192, 황금 당근 640 |
| 21 → 22 | 드래곤의 숨결 64, 삼지창 2 |
| 22 → 23 | 다이아몬드 블록 192, 전달체 1, 스펀지 16 |

#### 성급함 강화
- 해금(I) → II. 죽어도 다시 지급되는 영구 효과이고, 창의 스위치로 켜고 끌 수 있습니다.

| 단계 | 재료 |
|---|---|
| 해금 → I | 철 주괴, 금 주괴, 다이아몬드, 청금석, 레드스톤 가루, 석탄, 구리 주괴, 자수정 조각 각 64 |
| I → II | 회복 나침반 1, 자석석 1, 엔더 드래곤 머리 1 |

재료표는 `config.yml`의 `health-upgrade`, `haste-upgrade`에서 고칠 수 있습니다 ([설정](#설정-configyml) 참고).

#### 도전과제 조건
중요한 단계는 도전과제 조건을 채워야 강화할 수 있습니다.

**체력: 전체 도전과제 개수** (레시피 해금 제외, 26.3 기준 전체 126개)

| 시점 | 필요한 도전과제 |
|---|---|
| 10 → 11하트 (기본 체력 10하트를 넘어설 때) | 15개 |
| 15 → 16하트 | 40개 |
| 20 → 21하트 | 70개 |
| 22 → 23하트 (최대) | 100개 |

**성급함: 광질 도전과제를 모두 달성**

| 시점 | 필요한 도전과제 |
|---|---|
| 해금 | Stone Age (돌 캐기), Getting an Upgrade (돌 곡괭이), Acquire Hardware (철 제련), Isn't It Iron Pick (철 곡괭이), Diamonds! (다이아몬드) |
| I → II | Ice Bucket Challenge (흑요석), Hidden in the Depths (고대 잔해) |

- 재료는 조건을 채우기 전에도 미리 넣어 둘 수 있습니다. 재료를 다 넣어도 조건이 모자라면 강화 버튼이 보라색으로 남습니다.
- 강화 창 아랫줄의 지식의 책에 진행도가 나옵니다. 개수형은 "도전과제 12 / 15", 지정형은 도전과제마다 ✔/✘로 표시됩니다. 로드맵의 각 단계 설명에도 조건이 표시됩니다.
- 창을 연 채로 도전과제를 달성하면 창이 바로 갱신됩니다.
- 조건은 `health-upgrade.advancements`, `haste-upgrade.advancements`에서 바꾸거나 다른 단계에 추가할 수 있습니다. `"단계": 개수`(전체 개수) 또는 `"단계": [도전과제 키 목록]`(모두 달성) 형식입니다.

### 첫 접속 인증
- 처음 접속하면 **서버에서 정한 키**(`auth.key`)를 입력하기 전에는 움직일 수 없습니다. 화면 제목과 액션바로 안내가 나옵니다.
- `/인증 <키>`로 입력하거나 채팅에 키를 그대로 쳐도 됩니다. 인증 전 채팅은 다른 사람에게 보이지 않습니다.
- 인증 전에는 이동(고개 돌리기는 가능), 블록 부수기·설치, 상호작용, 아이템 버리기·줍기, 인벤토리 열기, 명령어(`/인증` 제외), 피해 주고받기, 배고픔 감소가 모두 막힙니다.
- 한 번 인증하면 다음 접속부터는 필요 없습니다.
- **`config.yml`의 `auth.key`를 반드시 정해 주세요.** 기본값 그대로면 콘솔에 경고가 뜹니다.

### 첫 접속 무작위 스폰 · 개인 스폰
- 처음 접속하면 오버월드 0,0 기준 **5000×5000** 범위(X, Z 각각 −2500~2500) 안의 무작위 위치에서 바로 스폰됩니다. 접속한 뒤 순간이동하는 방식이 아닙니다.
- 물, 용암, 나뭇잎, 선인장 위 등 위험한 곳은 피하고 두 칸 높이가 비어 있는 땅을 고릅니다.
- 그 위치가 **영구 개인 스폰**이 됩니다. 침대나 리스폰 앵커 없이 죽으면 항상 그곳에서 부활합니다. 그 사이 지형이 바뀌었으면 그 자리의 가장 높은 땅 위로 부활합니다.

### 영구 효과 (야간투시 · 성급함)
- 강화 창 아랫줄 스위치로 둘 다 켜고 끌 수 있습니다. 야간투시는 `/nv`로도 됩니다.
- 성급함 스위치는 해금하기 전에는 "잠김"으로 표시되고 누를 수 없습니다.
- 시스템이 주는 효과는 모두 **무한 지속, 입자 없음**(아이콘만 표시)입니다.
- 우유, 불사의 토템, `/effect clear`로 지워지지 않습니다. 죽으면 사라졌다가 부활할 때 다시 지급됩니다.

### 좌표

| 항목 | 동작 |
|---|---|
| F3 좌표 | 오버월드에서는 숨김, 네더/엔드에서는 보임 |
| Lunar Client 좌표 모드 | Apollo로 강제로 꺼짐 (아래 [클라이언트 제한](#클라이언트-제한) 참고) |
| 나침반 | 오버월드에서는 항상 **0,0**을 가리킴 (실제 월드 스폰과 무관). 네더/엔드에서는 바닐라처럼 빙글빙글 |
| 나침반 + F | 아래 참고 |

**나침반 들고 F(손 바꾸기)**
- 일반 나침반을 주로 쓰는 손에 들고 F를 누르면 현재 좌표가 채팅으로 나옵니다 (예: `123.46, -60, -77.5`).
- 확인한 나침반에는 "좌표 확인이 완료된 나침반" 설명이 붙고, 다시 쓰면 "이미 좌표 확인이 완료된 나침반입니다." 안내만 나옵니다 (나침반당 1회).
- 나침반 여러 개가 겹쳐 있으면 그 묶음 전체가 확인 완료로 바뀝니다.
- 자석석 나침반, 회복 나침반은 해당되지 않습니다.

### 양털 → 하얀 현수막
- 양털(모든 색)을 손에 들고 F를 누르면, 들고 있는 개수만큼 하얀 현수막으로 바뀝니다 (1:1).
- 인벤토리가 가득 차면 남는 현수막은 발밑에 떨어집니다.

### 통신 제한

| 항목 | 동작 |
|---|---|
| 채팅 | **반경 32블록 안**에 있는 플레이어에게만 `[지역] <이름> 내용`으로 보임. 서명 없는 메시지라 Mojang 채팅 신고 대상이 아님 |
| 명령어 | 일반 플레이어는 `/강화`, `/체력강화`, `/성급함강화`, `/nv` (와 영어 별칭)만 가능. `/msg`, `/tell`, `/me` 등 전부 차단 |
| 표지판 | 오버월드의 0,0 청크와 주변 8청크(블록 X·Z −16~31)에서만 글을 쓸 수 있음 |
| 책 · 모루 이름 변경 · 이름표 | 허용 (설정으로 막을 수 있음) |

**표지판 규칙**
- 오버월드 금지 구역에서 쓰면 내용이 `표지판은 / 0,0 근처에서만 / 사용이 가능합니다`로 바뀝니다.
- 네더·엔드에서는 어디서든 `표지판은 / 오버월드에서만 / 사용이 가능합니다`로 바뀝니다.
- 아무것도 쓰지 않은 표지판은 그대로 둡니다.

### 접속자 비공개 (익명성)
- **입장·퇴장·발전과제 메시지 없음.** 킥 메시지도 다른 사람에게 보이지 않습니다.
- **데스 메시지**는 누가 어떻게 죽든 `사람이 죽었다.` (빨간 굵은 글씨) 하나로 통일됩니다.
- **서버 목록**에서 인원과 플레이어 목록이 `???`로 숨겨집니다.
- **가까이(48블록) 있는 플레이어만** 내 화면에 존재합니다.
  - 그 밖의 플레이어는 탭 목록, P키 소셜 화면, 패킷 어디에도 없습니다.
  - 가까이 있는 플레이어도 이름은 `익명`으로 바뀌고, 이름표는 항상 숨겨지며, 탭 목록에도 나오지 않습니다.
  - 스킨은 보이기 때문에 직접 마주치면 알아볼 수 있습니다.
- **위치 표시줄(locator bar)**을 끄고, 관련 패킷도 차단합니다.
- **"n/m명이 자는 중"** 메시지를 차단합니다 (접속 인원 노출 방지).

### 0,0 무적지역 · 고정 엔더상자
- 오버월드 0,0 청크와 주변 8청크 안에서는 플레이어가 **피해를 입지 않습니다** (PvP 포함). 공허와 `/kill`은 예외입니다.
- 블록 설치·파괴와 적대 몹 스폰은 허용됩니다.
- 0,0 지면 위에 **부술 수 없는 엔더상자**가 자동으로 놓입니다. 부수기·폭발·위더 등으로 없어지지 않고, 사라지면 1분 안에 다시 생깁니다.
- 엔더상자는 플레이어마다 내용물이 따로라서 하나로 모두가 쓸 수 있습니다.

### 겉날개 금지
- 금지 중에는 겉날개가 걸린 액자를 **어떤 방법으로도 떼거나 부술 수 없습니다** (펀치, 화살, 폭발, 지지 블록 파괴, 피스톤, 크리에이티브 휠클릭 복사 포함).
- 어떻게든 겉날개를 얻었더라도 **활공할 수 없습니다** (glider 속성이 있는 모든 아이템 포함).
- 허용/금지는 콘솔의 `gss elytra on|off`로만 바꿉니다. 자동으로 풀리지 않습니다.

### 플레이어 머리
- 다른 플레이어에게 죽으면 그 사람의 머리가 떨어집니다 (화살 등 원거리 처치 포함).
- 머리 이름은 바닐라처럼 "닉네임의 머리"이고 스킨도 그대로입니다. **닉네임이 드러납니다.**
- 낙사, 몹, `/kill` 등 플레이어가 아닌 원인으로 죽으면 떨어지지 않습니다.
- `player-head.anonymous: true`로 바꾸면 닉네임 없이 스킨만 담습니다.

### 엔더드래곤
- 최대 체력이 **5배** (200 → 1000)입니다. 다시 소환한 드래곤에도 적용됩니다.

### 클라이언트 제한
- **바닐라와 Lunar Client만** 접속할 수 있습니다. 접속 5초 뒤 검사해서 그 외 클라이언트(Fabric, Forge, Feather, Badlion 등)는 내보냅니다.
  - 판별은 클라이언트가 보고하는 값(브랜드, 등록 채널, Apollo 연결)을 씁니다. 그래서 바닐라인 척 위조한 클라이언트는 막을 수 없습니다.
- **Lunar Client에서 강제로 끄는 모드** (Apollo 필요)

| 모드 · 옵션 | 이유 |
|---|---|
| Minimap | 좌표, 플레이어 레이더 |
| Coordinates | 좌표 HUD |
| Waypoints | 웨이포인트, 사망 지점 |
| LocatorBar | 플레이어 머리·이름 표시 |
| TeamView | 팀원 벽 너머 표시 |
| Markers | 핑 마커 (Lunar 친구와 공유 = 통신) |
| MumbleLink | 위치 기반 음성 채팅 |
| Waila 블록 좌표 | 바라보는 블록 좌표 |
| DirectionHud 팀원·웨이포인트·외부 마커 표시 | 위치 노출 |

## 예정 · 알려진 한계

**예정**
- 월드보더 3단계 (5000 → 7500 → 10000): 적용 방식 확정 후 구현
- 오프라인 플레이어 몸 (Rust 방식): 검토 완료, 세부 규칙 확정 후 구현

**알려진 한계**
- 게임 밖 채널(디스코드, Lunar·Essential 친구 목록 등)로 접속 여부가 알려지는 것은 막을 수 없습니다.
- 블록을 쌓아 글자를 만드는 식의 통신은 막을 수 없습니다.
- 네더 좌표 × 8 = 오버월드 좌표 역산은 의도적으로 허용합니다.
- 패킷을 직접 들여다보는 모드는 스킨 데이터에 들어 있는 원래 닉네임을 볼 수 있습니다 (바닐라·Lunar 화면에는 나오지 않음).
